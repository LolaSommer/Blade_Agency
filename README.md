🎨 Blade Agency — Responsive Landing Page

A modern responsive landing page for a creative digital agency.
Built with semantic HTML, SCSS architecture (BEM), and clean, accessible JavaScript logic.
🔗 Live Demo
https://lolasommer.github.io/Blade_Agency/

🚀 Tech Stack

HTML5 — semantic, accessible structure

SCSS (BEM) — modular and reusable code

JavaScript (ES6) — DOM logic, modals, smooth scroll

Responsive design — clamp() for adaptive typography and layout

Accessibility — full ARIA labeling and keyboard navigation

✨ Features

Smooth scrolling between sections with active link highlighting

Dynamic page counter in the footer

Three fully functional modals:

“Book a ticket” → “Thank you for your order”

“Ask a question” → “Thank you for your message”

Responsive adaptive layout for all screen sizes

Light and clean SCSS structure with variables and mixins
